# Code of Conduct

## Our Commitment

The MOGPTK community is committed to fostering an open, inclusive, and respectful environment for everyone. We welcome contributors and users of all backgrounds, identities, and levels of experience. We believe that scientific software benefits from diverse perspectives and constructive collaboration.

## Expected Behaviour

Members of the MOGPTK community are expected to:

- Be respectful and considerate in all interactions.
- Welcome constructive feedback and differing viewpoints.
- Focus discussions on improving the software and supporting its users.
- Use inclusive and professional language.
- Help create a collaborative environment where questions and contributions are encouraged.
- Act in ways that strengthen trust and collaboration within the community.

## Unacceptable Behaviour

The following behaviours are not acceptable:

- Harassment, discrimination, intimidation, or bullying of any kind.
- Offensive, abusive, or derogatory language.
- Personal attacks or deliberate disruption of discussions.
- Publishing another person's private information without their explicit permission.
- Any conduct that creates an unwelcoming, hostile, or unsafe environment.

## Scope

This Code of Conduct applies to all MOGPTK project spaces, including the GitHub repository, issue tracker, pull requests, discussions, documentation, project website, and any online or in-person events associated with the project.

## Reporting Concerns

If you experience or witness behaviour that violates this Code of Conduct, please contact the project maintainers by opening a private GitHub discussion or by emailing the corresponding maintainer listed in the repository.

All reports will be handled respectfully, confidentially where possible, and reviewed promptly.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct. They may remove, edit, or reject comments, commits, issues, pull requests, or other contributions that violate these guidelines. Repeated or serious violations may result in temporary or permanent restrictions on participation in the project.
